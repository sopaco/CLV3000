# 系统边界接口文档

本文档描述 CLV3000 的外部调用接口。CLV3000 是一个纯 GUI 桌面程序，对外暴露的接口非常"薄"：**没有 CLI 参数、没有 HTTP API、没有插件系统**。它的边界主要由四类东西构成：① 用户在桌面上操作的方式（窗口、托盘、关闭行为）；② 对内置便携版 ClamAV 的**子进程调用契约**（参数、stdin/stdout 文本协议）；③ 配置文件格式（`%APPDATA%\CLV3000\config.toml`）；④ 直接使用的 Win32 API 集合。对想要集成、分发或排查问题的人来说，最有价值的是理解第②项（协议约定）和第③项（配置格式）——它们决定了你能否让这个工具按你期望的方式工作。

---

## GUI 界面（人机接口）

CLV3000 的唯一操作入口是 Windows 桌面图形界面。用户不通过命令行或远程接口与它交互，而是通过主窗口的四个页面、系统托盘和窗口关闭行为来驱动它。下表概括了主窗口的组成：

| 区域 | 说明 |
|------|------|
| 仪表盘 | 大圆环状态（安全/存在风险）、上次全盘扫描摘要、闪电/全盘扫描快捷按钮 |
| 闪电扫描页 | 枚举进度（N/M 进程 + 文件数）、扫描百分比圆环、威胁卡片列表、取消 |
| 病毒库页 | 病毒库就绪状态、database 路径、手动更新按钮 |
| 全盘扫描页 | "包含可移动磁盘"复选框 + 扫描进度/威胁列表 |
| 自绘标题栏 | 左侧图标+标题、可拖拽区域、最小化/关闭按钮（关闭=隐藏到托盘） |
| 底部资源条 | CPU% / 内存% 实时指示条 |

### 托盘交互

| 操作 | 行为 | 代码位置 |
|------|------|---------|
| 双击图标 | 显示并聚焦主窗口 | `src/app.rs:280-286` |
| 右键菜单：显示主窗口 | 显示并聚焦主窗口 | `src/tray.rs:30-48` |
| 右键菜单：闪电扫描 | 切到闪电扫描页并立即启动扫描 | `src/tray.rs:30-48`、`src/app.rs:277-309` |
| 右键菜单：关于 / 退出 | 弹关于框 / 置 `allow_exit` 后真正退出 | `src/app.rs:304-307` |
| 窗口关闭按钮 | **默认拦截为"隐藏到托盘"**，只有托盘"退出"才结束进程 | `src/app.rs:352-355` |

托盘交互是"后台常驻"体验的关键：窗口关闭并不退出程序，它只是藏进托盘。对用户来说这符合"杀软常驻"的直觉；对维护者来说，唯一真正结束进程的路径是托盘"退出"菜单项，排查"为什么杀不掉"时先看这个逻辑。

## 子进程契约：clamscan.exe

`clamscan.exe` 是 CLV3000 唯一的扫描引擎。它由 `engine::run` 调用（`src/scan/engine.rs:46-58`），以子进程方式启动、通过标准输入/输出交换数据。理解这套契约就理解了 CLV3000 的扫描机制：

| 参数 | 值 | 含义 |
|------|----|------|
| `--no-summary` | - | 不输出结尾统计摘要，避免污染逐行解析 |
| `-v` | - | verbose：每个文件一行结果，程序靠它拿到逐文件进度 |
| `--file-list=-` | - | 从 stdin 流式读路径列表（**关键设计**：路径边走边喂，不攒列表） |
| `--database=<path>` | `paths::clamav_database_dir()` | 指定病毒库目录 |

**stdin 协议**：每行一个路径（`format!("{}\n", path)`，`src/scan/engine.rs:116`），写完关闭 stdin 表示结束——`drop(stdin)` 即 EOF 信号，这是"流式协议"的握手方式，无需额外命令。

**stdout 协议**：逐行 `path: status`，用 `rsplit_once(": ")` 从右边切分（Windows 路径的 `C:` 后紧跟 `\`，不会误伤）。`OK` → 干净；`<VirusName> FOUND` → 检出（`src/scan/engine.rs:162-173`）。

**隐藏窗口**：`creation_flags(CREATE_NO_WINDOW = 0x0800_0000)`，子进程不弹黑色控制台（`src/scan/engine.rs:24-25`）。

## 子进程契约：freshclam.exe

`freshclam.exe` 用于手动更新病毒库，由 `run_freshclam` 调用（`src/app.rs:213-233`）：

| 参数 | 值 | 含义 |
|------|----|------|
| `--datadir=<path>` | `paths::clamav_database_dir()` | 病毒库落盘目录 |

stdout/stderr 均重定向到 null；仅以退出码判断成功（非零 → toast 报错，`src/app.rs:228-232`）。同样 `creation_flags(0x0800_0000)` 隐藏窗口。

## 配置文件结构

**路径**：`%APPDATA%\CLV3000\config.toml`（`paths::config_file_path`，`src/paths.rs:43-45`）
**格式**：TOML，由 serde 序列化（`src/config.rs:22-31`）

这是程序唯一自己读写的持久化文件。理解它不需要关心序列化细节，只需要知道每个字段对应产品上的哪个行为：

| 配置项 | 类型 | 默认值 | 含义解读 |
|-------|------|-------|---------|
| `last_quick_scan` | `ScanRecord`(可选) | 无 | 上次闪电扫描摘要（`time`/`threats_found`/`scanned_count`）。它决定了仪表盘能显示"上次扫描·今天 09:12·未发现威胁"——没有它，仪表盘就没有"历史"概念 |
| `last_full_scan` | `ScanRecord`(可选) | 无 | 上次全盘扫描摘要。与上一项一起参与"系统状态：安全/存在风险"的计算（`src/app.rs:544-557`） |
| `ignored` | `IgnoredEntry[]` | `[]` | 用户忽略的威胁（`path` + `virus_name`），下次命中不再提示。它让"忽略"按钮变得可持久——重启后同样的威胁不会卷土重来 |
| `scan_removable_drives` | bool | `false` | 全盘扫描是否包含可移动盘（U 盘）。默认关是为了防止扫描时间不可控——插着一堆 U 盘的机器点一下全盘扫描可能扫几小时 |

**行为细节**：加载失败回退默认配置（`unwrap_or_default`）——配置坏了绝不打不开程序；保存时先 `create_dir_all`；忽略条目去重（`add_ignored` 先 `contains` 判断）。

**示例配置**：
```toml
last_quick_scan = { time = "2026-08-09 09:12", threats_found = 0, scanned_count = 342 }
last_full_scan = { time = "2026-08-08 21:40", threats_found = 1, scanned_count = 128744 }

[[ignored]]
path = "C:\\Program Files\\SomeApp\\plugin.dll"
virus_name = "PUA.Win32.Adware"

scan_removable_drives = false
```

## 环境约定（可执行文件相对布局）

CLV3000 采用"绿色分发"：程序假设它自己和便携版 ClamAV 放在同一个文件夹下。这个布局是运行时路径解析的基础（`src/paths.rs`）：

| 路径 | 来源 | 用途 |
|------|------|------|
| `<exe>\clamav\clamscan.exe` | `paths::clamscan_path` | 扫描引擎 |
| `<exe>\clamav\freshclam.exe` | `paths::freshclam_path` | 病毒库更新 |
| `<exe>\clamav\database\` | `paths::clamav_database_dir` | 病毒库文件（.cvd/.cld） |
| `%APPDATA%\CLV3000\config.toml` | `paths::config_file_path` | 配置持久化 |

## 使用的 Win32 API（平台集成面）

CLV3000 直接调用一批成熟的 Win32 API 完成平台能力，不引入重量级系统库。这张表对"这个程序在系统层面做了什么"给出了精确答案：

| API | 模块/函数 | 用途 |
|-----|----------|------|
| `CreateToolhelp32Snapshot` / `Process32FirstW`/`Process32NextW` | `src/scan/quick_scan.rs:82-101` | 进程快照枚举 |
| `CreateToolhelp32Snapshot`(MODULE) / `Module32FirstW`/`Module32NextW` | `src/scan/quick_scan.rs:107-129` | 进程模块枚举 |
| `GetLogicalDrives` / `GetDriveTypeW` | `src/scan/full_scan.rs:76-86` | 磁盘枚举与类型判定 |
| `CreateMutexW` / `GetLastError` | `src/single_instance.rs:14-19` | 全局单实例锁（`Global\CLV3000_SingleInstance_Mutex`） |
| `GetLocalTime` | `src/localtime.rs:19` | 极简本地时间戳 |
| `CommandExt::creation_flags` | `src/scan/engine.rs:57-58`、`src/app.rs:225-226` | 隐藏子进程控制台窗口 |

## 集成建议

如果要在生产环境使用或进一步开发这个工具，以下几点值得留意：

- **打包发布**：将 `target\release\clv3000.exe` 与便携版 `clamav\` 目录（clamscan.exe/freshclam.exe/依赖 DLL/database\*.cvd）放进同一文件夹分发；首次使用前建议手动跑一次 `freshclam.exe --datadir=clamav\database` 拉最新病毒库。
- **无静默/自动化接口**：本程序定位为"人肉触发的扫描工具"，不适合做自动化集成（无 CLI 参数、无退出码约定）；如需自动化扫描请直接调 `clamscan` 本身——它才是稳定的协议边界。
- **验证**：用 EICAR 测试文件跑全盘扫描验证检出链路；真机 Windows 上核对托盘、单实例、取消扫描三项（见 README 验证清单）。
