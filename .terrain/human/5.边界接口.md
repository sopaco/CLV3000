# CLV3000 边界接口

边界接口是 CLV3000 向外部世界（用户、脚本、操作系统）暴露的全部"入口"清单。理解这些接口，就能回答两个问题：**"怎么指挥它做事"**（CLI 参数、右键菜单、GUI 按钮）和 **"它会把什么写进你的系统"**（配置文件、缓存、注册表、隔离区）。对杀毒工具来说，第二类接口尤其重要——用户有权知道它碰了系统哪些地方。

## 接口总览

| 接口类型 | 入口 | 主要用途 |
|---------|------|---------|
| 命令行参数 | `clv3000.exe` 启动参数 | 定向扫描、强制隔离、静默托盘 |
| 文件/文件夹右键菜单 | Explorer shell verb `CLV3000Scan` | 快速定向扫描 |
| 系统托盘 | 托盘图标 + 菜单 | 唤回窗口、快速扫描、退出 |
| 配置文件 | `config.toml` | 扫描设置、忽略清单、上次扫描信息 |
| 缓存文件 | `scan_cache.tsv` / `scan_cache_paths.tsv` | 基因缓存（性能加速） |
| 注册表（Windows） | `HKCU\...\Run` 与 shell verb | 自启项与右键菜单 |
| 隔离区 | `quarantine_entries.json` + 隔离文件 | 威胁处置的落点 |

## CLI 命令行参数

CLV3000 的命令行入口在 `src/main.rs`。参数在窗口创建之前解析，其中 `--force-quarantine` 直接执行后退出，`--scan-path` 走"单实例锁 → 冷启动扫描或热转发"两条路径。

| 参数 | 格式 | 行为 | 代码位置 |
|------|------|------|---------|
| `--scan-path <path>` | 单路径 | 定向扫描指定文件或文件夹；若已有实例在跑则转发请求后退出 | `src/main.rs::parse_scan_path`、`src/single_instance.rs` |
| `--force-quarantine <original> <dest>` | 两个路径 | 执行强制隔离（杀占用进程 + UAC 提权搬移），执行后退出 | `src/main.rs`（单实例锁之前解析）、`src/quarantine.rs::force_quarantine` |
| `--tray-only` | 无值 | 以托盘模式启动，不创建主窗口（自启与静默驻留用） | `src/main.rs`、`src/tray.rs` |

使用示例：

```text
# 定向扫描单个文件（冷启动）
clv3000.exe --scan-path C:\temp\suspicious.exe

# 已有一个实例在跑，把新扫描请求转发给它（自身退出）
clv3000.exe --scan-path D:\downloads

# 开机自启的静默托盘模式
clv3000.exe --tray-only

# 强制隔离（供 UAC 提权子进程调用，正常用户不用直接执行）
clv3000.exe --force-quarantine "C:\bad\virus.dll" "C:\ProgramData\CLV3000\quarantine\..."
```

注意 `--force-quarantine` 是**供提权子进程内部调用的命令**，它出现在 CLI 是为了让 UAC 提权后的进程用同一套二进制完成搬移（`src/quarantine.rs` 会以提权方式重新拉起自身）。普通用户遇到"文件被占用"的隔离失败时，走的也是这条路径，但由 GUI 弹确认框后自动调用。

## Explorer 右键菜单

Windows 资源管理器的文件/文件夹右键菜单，由 `src/context_menu.rs` 注册。这是 CLI `--scan-path` 的用户友好形态——同一条链路，不同入口。

| 项目 | 值 |
|------|-----|
| 菜单项名称 | `用 CLV3000 扫描`（`MENU_LABEL="Scan with CLV3000"`） |
| Shell verb 键名 | `CLV3000Scan`（`VERB_KEY`） |
| 执行命令 | `clv3000.exe --scan-path "%1"` |
| 注册位置 | 注册表 Shell verb 键（Explorer 扩展） |
| 适用对象 | 文件与文件夹 |
| 生命周期 | 设置页提供注册/卸载开关；卸载时清理注册表项 |

右键菜单与其它扫描入口共享同一条路径：verb 命令 → `src/main.rs` 的 `--scan-path` 分支 → 单实例锁判断 →（已有实例）转发或（冷启动）自动扫描 → 扫描页渲染。详见 `3.工作流.md` 工作流三。

## 系统托盘

托盘图标是窗口隐藏后与用户的唯一交互入口。由 `src/tray.rs` 创建与持有（图标句柄不能 drop，否则图标消失）。

| 交互 | 事件 | 响应 |
|------|------|------|
| 双击图标 | `TrayIconEvent::Click` | 显示主窗口并激活到前台 |
| 菜单 "Show Main Window" | `MenuEvent` | 显示主窗口并激活到前台 |
| 菜单 "Quick Scan" | `MenuEvent` | 直接发起闪电扫描（无需进主窗） |
| 菜单 "About" | `MenuEvent` | 打开 About（模态或全屏，见 `about_dialog.rs`） |
| 菜单 "Quit" | `MenuEvent` | 退出应用（走 `Exiting` 生命周期） |

事件经 `TrayIconEvent::receiver()` / `MenuEvent::receiver()` 进入 channel，由 `wakeup.rs` 转发线程唤醒 UI 线程消费——这是 eframe 拿不到 `EventLoopProxy` 时的标准解法（ADR 五）。

## 配置文件：`config.toml`

配置文件位于 `app_data_dir`：Windows `%APPDATA%\CLV3000\config.toml`，macOS `~/Library/Application Support/CLV3000/config.toml`。由 `src/config.rs` 读写，结构基于 `Config` / `ScanSettings`。

| 配置项 | 类型 | 说明 |
|--------|------|------|
| 扫描设置 | `ScanSettings` | 是否扫描系统文件、是否记录上次扫描等扫描行为开关 |
| 忽略清单 | `ignored_threats` | 用户选择"忽略"的威胁路径列表；后续扫描到这些路径直接跳过 |
| 上次扫描信息 | `last_scans` | 历史扫描结果概览（Dashboard 页展示） |

**配置语义**：`config.toml` 是纯文本 TOML，缺省时用默认值填充（首次运行不报错）；文件存在但解析失败时 `ConfigError` 会明确区分"损坏"与"不存在"，提示用户而不静默丢弃。用户可直接用记事本编辑它（例如手工追加忽略项），CLV3000 设计上接受这种"人工救援"。

## 缓存文件：`scan_cache.tsv` / `scan_cache_paths.tsv`

缓存位于 `app_data_dir` 下，由 `src/scan/cache.rs` 管理，是**性能加速层**，非安全保证。

| 文件 | 内容 | 容量上限 | TTL |
|------|------|---------|-----|
| `scan_cache.tsv` | 文件内容 BLAKE3 基因哈希 → 上次扫描结论（干净/病毒名） | `MAX_ENTRIES` 200,000（压缩到 `TARGET_ENTRIES` 160,000） | 30 天 |
| `scan_cache_paths.tsv` | 路径 → 大小 + 修改时间 + 哈希，跳过未变化文件 | `MAX_PATH_ENTRIES` 200,000（压缩到 160,000） | 30 天 |

两份都是 TSV 明文，可安全删除——删掉只损失加速效果，不影响扫描正确性。

## 注册表（Windows）

注册表只用于两项**系统集成**，不存业务数据：

| 位置 | 用途 | 管理代码 |
|------|------|---------|
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | 开机自启项（`--tray-only` 静默启动） | `src/autostart.rs` |
| Shell verb 键（Explorer 扩展） | 右键菜单注册 | `src/context_menu.rs` |

## 隔离区

隔离区是威胁处置的落点，由 `src/quarantine.rs` 管理。

| 项目 | 值 |
|------|-----|
| 位置 | `app_data_dir` 下的隔离区目录 |
| 记账文件 | `quarantine_entries.json`（原路径、原始文件名、隔离时间、病毒名） |
| 隔离动作 | 文件**搬移**到隔离区（可逆，非删除） |
| 管理入口 | 设置页隔离区列表（还原 / 永久删除） |
| 强制隔离 | 文件被占用时杀进程 + UAC 提权搬移（`--force-quarantine`，需确认） |

隔离区的全部操作都有记账可追溯，还原依赖记账精确搬回原路径。`6.数据库概览.md` 对"准持久化"文件有完整说明。

## 使用场景速查

| 我想做… | 用什么入口 |
|---------|-----------|
| 快速扫一下当前进程 | 主界面"闪电扫描"或托盘菜单 Quick Scan |
| 定期全盘安检 | 主界面"全盘扫描" |
| 扫单个文件/文件夹 | 右键"用 CLV3000 扫描"或 `--scan-path` |
| 处理扫描出的威胁 | 结果页"隔离/忽略" |
| 恢复误报隔离 | 设置页隔离区 → 还原 |
| 更新病毒库 | 病毒库页"手动更新" |
| 开机自动就位 | 设置页开启自启（`--tray-only` 静默驻留） |
| PE 环境脚本化扫描 | `--scan-path` 批量调用（同实例热转发） |
